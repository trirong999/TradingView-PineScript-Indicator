# 📈 TradingView Pine Script Laboratory

Welcome to a personal repository dedicated to collecting, developing, and testing custom **Pine Script (v5 / v6)** indicators for **TradingView**. This workspace serves as a centralized archive for technical analysis tools, custom scripts, and experimental logic designed for price action analysis.

* **Custom Indicators:** A collection of custom-built indicators tailored for specific trading conditions and visual chart analysis.

* **Pine Script v5 & v6:** Written using the latest Pine Script standards for optimal performance and compatibility on TradingView.
